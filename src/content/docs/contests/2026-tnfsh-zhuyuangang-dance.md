## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-07 18:00（已截止） |
| 參賽對象 | 高中職、五專；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 3 至 12 人 |
| 費用 | 每隊 2,500 元 |
| 主辦 | 國立臺南第一高級中學韓舞社、國立臺南第一高級中學熱舞社 |
| 類別 | [表演藝術](/subjects/performing-arts/) |

## 要交什麼

- 報名：團隊報名資料，並上傳家長同意書與參賽者名冊 PDF（線上繳交）
- 報名（K-POP COVER 組）：所仿造舞台或練習室影片的連結（線上繳交）
- 報名或錄取後（熱舞組）：比賽音檔（線上繳交）
- 比賽當天檢錄：核章後的參賽者名冊（含學生證黏貼聯）紙本與學生證正本（現場）
- 比賽：2 分 30 秒至 5 分鐘的舞蹈演出（現場）

## 獎項

熱舞組與 K-POP COVER 組分別計算，名額依參賽隊數而定（19 至 20 隊取前三名暨優等一名）：冠軍獎學金 8,000 元、亞軍 5,000 元、季軍 3,000 元、優等 2,000 元，皆附獎座及獎狀；兩組另各取最佳造型獎一名，頒獎座及獎狀。獎狀只發團體獎狀一紙。
