## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-13（已截止） |
| 參賽對象 | 國小、國中、高中職；高中職自成一組 |
| 地區 | 屏東縣 |
| 隊伍 | 1 至 5 人；須有指導老師 |
| 主辦 | 屏東縣政府教育處、國立屏東科技大學 |
| 類別 | [工程與製造](/subjects/engineering/)、[技藝與技能](/subjects/skills/)、[資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 報名：網路報名表（含競賽當天用餐葷素選項）（線上繳交）
- 報名：學校核章的在學證明，及每位選手簽署的肖像權、著作權與個人資料同意書紙本（郵寄或親送）
- 初賽與決賽：在屏東縣南州國中體育館操控無人機比賽；虛擬飛行技能挑戰賽的設備由大會提供（現場）

## 獎項

高中職、國中、國小各組金牌 1 隊、銀牌 2 隊、銅牌 3 隊；佳作：無人機足球賽為進入淘汰賽而未得上述獎項的隊伍，其他項目取未得上述獎項隊伍的 60%，參賽選手及指導老師均可獲得獎狀。得獎隊伍指導老師另依名次記功或嘉獎。
