## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-30 |
| 參賽對象 | 高中職、大專；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 人；可有指導老師 |
| 費用 | 優惠價 1500 元（ICDL 原廠認證費為 2480 元） |
| 主辦 | 國立成功大學資安科技研究中心、國立成功大學計算機與網路中心、財團法人中華民國電腦技能基金會 |
| 類別 | [資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 競賽：ICDL IT Security 資訊安全測驗，作答時間 45 分鐘（現場）

## 獎項

高中職組、大專組依競賽結果頒發冠軍、亞軍、季軍、優勝 7 名、佳作若干名獎狀；成績須達 ICDL 國際認證通過標準（及格 75% 以上）才列入排名；獲獎選手的指導老師贈感謝狀。
