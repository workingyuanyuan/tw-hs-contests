## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-12-31 |
| 參賽對象 | 國小、國中、高中職、五專、大專、社會人士；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 至 2 人；可有指導老師 |
| 費用 | 兒童組 NT$800、青少年組 NT$1,000、成人組 NT$1,200（另需自付全家 FamiPort 展開圖列印費） |
| 主辦 | 蝶映藝術文化有限公司 |
| 類別 | [設計](/subjects/design/)、[美術](/subjects/fine-arts/) |

## 要交什麼

- 報名及繳件：於全家 FamiPort 列印官方參賽紅包袋展開圖（海外參賽者自行下載 PDF 列印），摺成紅包袋並創作羊年插畫，連同線上報名後列印之報名表（PDF）一併郵寄。（郵寄或親送）

## 獎項

各組第一至三名：中英文正式獎狀、作品上架全家 FamiPort 兩個月、正式新聞稿露出；特優、優選：獎狀、新聞稿列名。學生得獎者之指導老師獲正式感謝函，就讀學校一併列入新聞稿。
