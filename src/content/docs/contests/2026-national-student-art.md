## 重點

| 項目 | 內容 |
| --- | --- |
| 參賽對象 | 國小、國中、高中職、五專、大專；高中職自成一組 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 人；可有指導老師 |
| 主辦 | 國立臺灣藝術教育館 |
| 類別 | [美術](/subjects/fine-arts/)、[設計](/subjects/design/) |

## 要交什麼

- 初賽：西畫、書法、平面設計、漫畫、水墨畫或版畫作品一件（依各類規格），由學校選送縣市初賽
- 決賽：初賽錄取作品由縣市教育局（處）送件；高中（職）組除書法類外另附 100-200 字作品介紹（現場）
- 決賽（書法類）：取得決賽代表權者依初賽承辦單位通知參加當地現場書寫（現場）

## 獎項

決賽分特優、優等、甲等、佳作四等，佳作以上學生及指導老師各獲獎狀乙張；特優受邀出席頒獎典禮領獎。
