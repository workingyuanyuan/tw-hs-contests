## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-10-19（已截止） |
| 參賽對象 | 國小、國中、高中職；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 隊伍 | 1 人 |
| 費用 | 1000元；學校自辦考場每位考生900元 |
| 主辦 | 保加利亞數學無國界組委會 |
| 類別 | [數學](/subjects/math/) |

## 要交什麼

- 第一輪競賽：60 分鐘作答 20 題英文填充題（Group1～Group6 附中文翻譯），實體考場或非考區線上考場（現場）
- 第二輪競賽：第二輪積分賽考試（線上繳交）
- 夏季總決賽（前兩輪獲獎牌者及配額）：於保加利亞內賽伯爾參加決賽（現場）

## 獎項

每輪頒金獎（5%）、銀獎（10%）、銅獎（15%）獎牌及證書，其他參與者獲參與證書；答對率 50% 或銅獎以上另獲合格證書；前兩輪獲至少一枚獎牌者可進入總決賽。
