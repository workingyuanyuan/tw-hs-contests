## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2027-03-15 12:00 |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 至 3 人；須有指導老師 |
| 主辦 | 全國高級中等學校圖書館輔導團（國立中興高級中學） |
| 類別 | [語文與寫作](/subjects/language-and-writing/)、[自然科學](/subjects/science/)、[社會人文](/subjects/humanities/) |

## 要交什麼

- 投稿（第一學期或第二學期）：A4 直式 4 至 10 頁 PDF 檔，不含封面，含圖檔不超過 5MB，依前言至參考文獻六大架構撰寫（線上繳交）
- 投稿時：作品切結書，每篇（組）一張，交學校留存

## 獎項

依年級評分，分特優、優等、甲等三種等第，頒發獎狀；總得獎率不超過 50%。
