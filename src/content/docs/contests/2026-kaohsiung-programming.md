| 參賽對象 | 國中、高中職；高中職自成一組 |
| 地區 | 高雄市 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 人；須有指導老師 |
| 主辦 | 高雄市政府教育局 |
| 類別 | [資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 初賽：各校於 10 月 23 日前或自訂日期辦理初賽，選出推薦學生
- 複賽：3 小時線上讀題，以 C、C++、Python 等語言解題並上傳程式碼，依答對題數與總耗時評分（現場）

## 獎項

高中職組複賽與國中組各取第一名 1 名獎金 2,000 元、第二名 2 名各 1,500 元、第三名 3 名各 1,000 元，皆附獎狀；佳作最多取報名人數的四分之一，頒獎狀。非高雄市政府教育局所屬學校成績優異者只頒優選獎狀及參賽證明。高中職組複賽並選拔優勝學生參加教育部舉辦之決賽。
