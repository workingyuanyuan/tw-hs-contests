## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-22（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 3 至 4 人；須有指導老師 |
| 費用 | 區域賽、全國決賽各 300 元/人（提供午餐便當；低收入戶學生全程參與者退回報名費） |
| 主辦 | 中華民國物理教育學會、東海大學應用物理學系 |
| 類別 | [自然科學](/subjects/science/) |

## 要交什麼

- 區域賽：以主辦單位現場提供之器材限時完成量測實驗，製作簡報或海報，進行 3 分鐘口說報告與 4 分鐘評審詰問（現場）
- 全國決賽：同區域賽形式：現場實驗量測、製作簡報或海報、3 分鐘口說報告與 4 分鐘評審詰問（現場）

## 獎項

區域賽與全國決賽各組頒前三名及佳作一名，另由評審會議決定「最佳科學量測獎」及「最佳不確定度估計獎」若干隊；全程完成者核發參賽證書，獎狀以下載連結提供，視經費提供獎金或獎品。
