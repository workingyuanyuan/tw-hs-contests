## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-22（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 3 至 4 人；須有指導老師 |
| 費用 | 區域賽 300 元/人；全國決賽 300 元/人（低收入戶學生全程參與退回報名費） |
| 主辦 | 中華民國物理教育學會、東海大學應用物理學系 |
| 類別 | [自然科學](/subjects/science/) |

## 要交什麼

- 區域賽及全國決賽：限時使用現場提供器材進行物理實驗量測與數據分析，並製作簡報（建議 PPT 或 PDF 檔）進行 3 分鐘口說報告與 4 分鐘評審詰問（現場）

## 獎項

區域賽及決賽各組頒發前三名及佳作一名獎狀，並設「最佳科學量測獎」及「最佳不確定度估計獎」若干隊伍，視實際經費狀況提供獎金或獎品；全程完成競賽隊員核發參賽證書，指導教師頒發感謝狀。
