## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-09-30 22:00（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 1 至 3 人；可有指導老師 |
| 主辦 | 教育部、環境部 |
| 類別 | [自然科學](/subjects/science/)、[農業與環境](/subjects/agriculture-and-environment/) |

## 要交什麼

- 初選：報名表與創意說明書（A4，1 萬字、30 頁內）（線上繳交）
- 複選：成果報告書、著作權授權同意書與 3 至 5 分鐘成果影片（上傳 YouTube 後提供連結）（線上繳交）
- 複選成果發表：依抽籤順序向五位評選委員各發表 7 分鐘、答詢 5 分鐘，並布置成果展示區（現場）

## 獎項

普通型、技術型高級中等學校組分別選出金牌 1 名（獎金 2 萬元）、銀牌 2 名（1 萬 5 千元）、銅牌 3 名（1 萬元）與佳作若干名，皆頒獎狀；金銀銅牌每位指導老師另得 3,000 元。入圍複選每隊得實驗材料補助 3,000 元及入圍證明書；另有創意獎，總獎金 2 萬元。
