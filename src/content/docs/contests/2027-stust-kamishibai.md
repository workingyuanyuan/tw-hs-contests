## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-12-31 |
| 參賽對象 | 高中職、五專；只限高中職學生 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 須有指導老師 |
| 主辦 | 南臺學校財團法人南臺科技大學人文社會學院應用日語系 |
| 類別 | [外語](/subjects/foreign-languages/)、[表演藝術](/subjects/performing-arts/)、[美術](/subjects/fine-arts/) |

## 要交什麼

- 第一階段報名：於南臺科技大學應用日語系網頁「第一階段報名」輸入報名資料（線上繳交）
- 第二階段報名：紙本報名表（加蓋學校關防及附學生證正反面影本）、授權同意書、指定故事題材名稱，以及燒錄繪製圖片（半成品亦可）之光碟片（郵寄或親送）
- 現場比賽：5 分鐘日語看圖說故事表演（自選指定日本故事題材並繪製圖畫，以 40×28 公分紙張放入大會木製框架抽拉演出，可自備背景音樂與現場音效）（現場）

## 獎項

第一名：獎狀及獎金 8,000 元；第二名：獎狀及獎金 5,000 元；第三名：獎狀及獎金 3,000 元；佳作獎（若干組）：獎狀及獎金 1,000 元。
