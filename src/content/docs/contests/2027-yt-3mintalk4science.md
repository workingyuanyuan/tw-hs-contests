## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2027-01-31 11:00 |
| 參賽對象 | 國中、高中職、五專；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 至 3 人；可有指導老師 |
| 主辦 | 財團法人遠哲科學教育基金會 |
| 類別 | [外語](/subjects/foreign-languages/)、[自然科學](/subjects/science/) |

## 要交什麼

- 初賽：1 頁 A4 英文研究摘要、3 頁 PPT 簡報、30 秒至 1 分鐘英文介紹研究主題影片，連同參賽聲明與著作授權同意書上傳（線上繳交）
- 決賽：海報一份
- 決賽：3 分鐘英語短講與 2 分鐘英文問答，團體組每位隊員皆須發表（現場）

## 獎項

高中職組、國中組各頒金、銀、銅獎各 1 隊：金獎團體 24,000 元、個人 15,000 元，銀獎團體 18,000 元、個人 12,000 元，銅獎團體 12,000 元、個人 8,000 元，皆附獎牌、證書，指導老師另有獎金；另設創意獎、永續獎、最佳海報獎；決賽未得獎隊伍每人佳作獎狀，初賽名次前 25% 每人入選獎狀。
