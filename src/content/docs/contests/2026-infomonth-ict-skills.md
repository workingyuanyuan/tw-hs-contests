## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-09-17（已截止） |
| 參賽對象 | 高中職、大專；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 至 5 人；須有指導老師 |
| 主辦 | 資訊月活動委員會 |
| 類別 | [資訊與 AI](/subjects/ai-and-computing/)、[技藝與技能](/subjects/skills/)、[商管與行銷](/subjects/business/) |

## 要交什麼

- 報名：指導老師線上填寫團隊資料後列印的參賽報名表，以掛號寄至所屬區推廣中心（郵寄或親送）
- 全國實機競賽：40 分鐘內依題目要求完成操作題並存檔（Python、C/C++、Excel、Word、PowerPoint 或會計軟體，依組別而定）（現場）

## 獎項

全國排名：個人組前十名頒優勝獎狀；團體組前五名，第一名頒獎盃、第二至五名頒獎牌，並頒獎狀。北、中、南各區另取個人組前十名頒獎狀、團體組前五名頒獎牌及獎狀。團體成績以各隊分數最高的前 3 名加總。全國參賽不足 30 人或 10 隊的項目，僅頒全國團體組前三名及全國個人前十名。
