## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2027-01-05 |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 3 至 6 人；須有指導老師 |
| 主辦 | 景文科技大學智慧創新學院 |
| 類別 | [商管與行銷](/subjects/business/)、[資訊與 AI](/subjects/ai-and-computing/)、[設計](/subjects/design/) |

## 要交什麼

- 初賽：專題研究報告書全文電子檔（PDF 檔，依規定格式撰寫，以 10 頁為原則）（線上繳交）
- 總決賽（資料繳交）：簡報電子檔（PowerPoint 或 odp 檔，20 頁為限）（線上繳交）
- 總決賽（現場發表）：8 分鐘上台口頭發表（現場）

## 獎項

各類組獎項：第一名 1 名 3,000 元（等值禮券）及獎狀乙紙；第二名 1 名 2,500 元（等值禮券）及獎狀乙紙；第三名 1 名 2,000 元（等值禮券）及獎狀乙紙；優勝 5 名獎品一份及獎狀乙紙；佳作若干名獎狀乙紙。若該類組報名隊伍低於 7 隊，只取第 1～3 名及若干名優勝。
