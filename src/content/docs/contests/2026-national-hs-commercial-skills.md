## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-06-12（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 人 |
| 費用 | 報名費每一職種每人新臺幣 1,700 元 |
| 主辦 | 教育部 |
| 類別 | [技藝與技能](/subjects/skills/)、[商管與行銷](/subjects/business/)、[資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 學科競賽：各職種學科測驗，佔總成績 20% 以下（現場）
- 術科競賽：各職種實作測驗，例如網頁設計 4 小時、程式設計 3 小時、數位動畫 5 小時；佔總成績 80% 以上（現場）
- 術科第一階段（平面設計、職場英文）：平面設計：視覺設計手繪表現 2 小時；職場英文：英文寫作 40 分鐘（現場）
- 術科第二階段（平面設計、職場英文入圍者）：平面設計：數位設計 4 小時；職場英文：職場英語簡報製作及口頭簡報 8 小時（現場）

## 獎項

九個職種共設金手獎 72 名、優勝 148 名，由大會頒獎；各職種金手獎前五名另得點將家金手獎獎金（選手 70%、指導老師 30%）。優勝學生可依技藝技能優良學生申請甄審及保送入學大專校院；各職種前三名可申請相關職類丙級或單一級技能檢定免術科測試。參賽學生均核發參賽證明。
