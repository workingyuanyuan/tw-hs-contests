## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-12-10 16:00 |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 3 人；可有指導老師 |
| 費用 | 每組 2,400 元 |
| 主辦 | 淡江大學化學系 |
| 類別 | [自然科學](/subjects/science/) |

## 要交什麼

- 第一階段：化學館闖關活動（達成指定任務並蓋章）（現場）
- 第二階段：化學實驗實作與電腦模擬，並提出實驗結果分析書面報告（現場）

## 獎項

金牌獎 2 組每組 4,500 元及獎狀、銀牌獎 4 組每組 3,000 元及獎狀、銅牌獎 6 組每組 2,400 元及獎狀；完成闖關進入實作者頒予入選獎狀。
