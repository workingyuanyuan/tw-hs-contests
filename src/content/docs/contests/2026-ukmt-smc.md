## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-09-21（已截止） |
| 參賽對象 | 國小、國中、高中職；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 隊伍 | 1 人 |
| 費用 | 學校自辦考場每位考生 1100 元 |
| 主辦 | 英國UKMT(United Kingdom Mathematics Trust) |
| 類別 | [數學](/subjects/math/) |

## 要交什麼

- 學校自辦考場：90 分鐘筆試答題卷（22 題選擇題及 3 題 000-999 三位數計算題），由學校掃描回傳（現場）
- 個人考場：高雄實體考區：於考區現場作答 90 分鐘筆試（現場）
- 個人考場：線上考區（非考區縣市、東部及離島）：以 UKMT 亞洲區線上系統作答，並以另一設備開啟 Zoom 監考（線上繳交）

## 獎項

金獎授予全球排名約前 11% 考生、銀獎約前 22%、銅獎約前 33%，未獲獎者可獲參與證書；另設學校最佳獎（全校最高分者）與年級最佳獎（各年級校內最高分者）。由 UKMT 英國組委會授予英文證書。
