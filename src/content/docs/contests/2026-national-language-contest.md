## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-10-20（已截止） |
| 參賽對象 | 國小、國中、高中職、五專、大專、社會人士；高中職自成一組 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 至 4 人；可有指導老師 |
| 主辦 | 教育部 |
| 類別 | [語文與寫作](/subjects/language-and-writing/) |

## 要交什麼

- 報名（由競賽單位辦理）：網路報名，並掛號寄送各項各組競賽報名單與讀者劇場所採用文本（郵寄或親送）
- 個人賽決賽：每人限 1 項：當場抽題演說、情境式演說（含問答）、朗讀，或限時作文、毛筆楷書寫字、字音字形（現場）
- 團體賽（讀者劇場）決賽：以臺灣台語、臺灣客語或臺灣原住民族語言演出自行創作或改編之文本，並回答評判提問（現場）

## 獎項

依參賽人數比例錄取特優（前 25%）、優等（中間 50%）、甲等（後 25%），未滿 70 分不列等第。個人賽特優發給獎座及獎狀，優等、甲等發給獎狀；讀者劇場特優隊伍發給獎座 1 座，得等第隊伍每名競賽員發給獎狀。
