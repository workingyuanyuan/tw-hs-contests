## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-10-30 17:00（已截止） |
| 參賽對象 | 國小、國中、高中職；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 至 3 人；須有指導老師 |
| 費用 | 自行報名隊伍初審每件 500 元、複審每件 1,500 元；縣市推薦隊伍免初審費，複審每件 1,200 元 |
| 主辦 | 國立臺灣師範大學 |
| 類別 | [工程與製造](/subjects/engineering/)、[設計](/subjects/design/) |

## 要交什麼

- 初審報名（自行報名隊伍）：2 頁內作品摘要說明表 PDF、報名單位總表（學校簽章）、工本費繳費證明、每位學生的知情同意書（線上繳交）
- 複審報名（晉級及縣市推薦隊伍）：10 頁內作品完整說明表、國內外專利查詢資料，縣市推薦隊伍另附推薦公文或獎狀（線上繳交）
- 複審：實體發明作品（長寬 90×60 公分內、10 公斤內）現場展示，每次 2 分鐘向評審解說及操作（現場）
- 賽後（金牌隊伍）：約 2 分鐘至 2 分鐘半的作品說明影片

## 獎項

各學級組分六類評定：總成績前 10% 金牌、11% 至 30% 銀牌、31% 至 60% 銅牌、61% 至 100% 佳作，皆頒獎狀；英文發表特別獎國小、國中、高中各 2 隊。
