## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2027-05-20 |
| 參賽對象 | 國小、國中、高中職、五專、大專、社會人士；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 隊伍 | 不設指導老師 |
| 主辦 | 巴哈姆特 |
| 類別 | [影音](/subjects/video/)、[美術](/subjects/fine-arts/)、[設計](/subjects/design/) |

## 要交什麼

- 報名交件（動畫組）：20 分鐘以內完整 2D、3D 或停格/偶動畫原始檔（MP4/MOV，1920x1080 以上）（線上繳交）
- 報名交件（漫畫組）：原創單篇完整頁漫（17-46 頁黑白稿）或條漫（40 格以上）JPG 檔（線上繳交）
- 報名交件（遊戲組）：Android APK/Google Play 連結或 Windows 主程式/Steam 連結（繁中或英文）（線上繳交）

## 獎項

各組分別頒發：金賞 50,000 元、銀賞 30,000 元、銅賞 10,000 元（皆附獎盃與巴哈姆特 GNN 專訪）；優選賞紀念獎章；人氣賞 5,000 元與紀念獎章；各組特別賞 4,000 元與獎盃。
