## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-23 17:00（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 4 至 6 人；須有指導老師 |
| 主辦 | 臺北城市科技大學應用外語系 |
| 類別 | [外語](/subjects/foreign-languages/)、[表演藝術](/subjects/performing-arts/) |

## 要交什麼

- 報名：Google 表單報名表（線上繳交）
- 報名：紙本報名表（指導老師簽名、參賽選手學生證影本、學校關防或科章），以掛號寄送（郵寄或親送）
- 初賽：電子郵件寄送報名表掃描檔、評分表，及含台詞檔、初賽影片（不含背景音樂與音效、不得出現選手影像）與決賽影片的雲端資料夾連結（線上繳交）
- 決賽：現場為 5 分鐘內影片配音演出，可自備道具製造音效（現場）

## 獎項

主修組與非主修組分別評選團體獎前三名、佳作數名及優秀配音員獎數名，頒發獎狀；進入決賽者頒發決賽證明。
