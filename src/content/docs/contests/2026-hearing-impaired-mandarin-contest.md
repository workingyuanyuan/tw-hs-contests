| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-09-30（已截止） |
| 參賽對象 | 國小、國中、高中職、大專、社會人士；高中職自成一組 |
| 地區 | 全國 |
| 主辦 | 教育部國民及學前教育署 |
| 類別 | [語文與寫作](/subjects/language-and-writing/) |

## 要交什麼

- 報名：網路報名後列印表件核章（社會組不須核章），掃描上傳；社會組甲組另上傳聽力證明文件（線上繳交）
- 初賽、決賽（口語、手語演講）：演講稿（.doc、.docx 或 .odt，A4 直式橫書、標楷體 14 級字）（線上繳交）
- 分區初賽：現場朗讀、口語或手語演講、作文或書法比賽（現場）
- 全國決賽（初賽特優、優等為原則）：現場朗讀、口語或手語演講、作文或書法比賽（現場）

## 獎項

初賽各組擇優錄取前三名優勝（依報名人數增額錄取），發予獎狀及獎品；決賽各組擇優錄取前三名優勝者，由主辦單位給予獎狀及獎品。初賽、決賽優勝學生及指導教師 1 人敘獎：特優記功 1 次、優等嘉獎 2 次、甲等嘉獎 1 次。決賽未獲獎者核發參賽證明。
