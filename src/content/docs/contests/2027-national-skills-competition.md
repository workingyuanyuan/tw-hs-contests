## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-12-07 24:00 |
| 參賽對象 | 國中、高中職、五專、大專、社會人士；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 1 至 2 人 |
| 費用 | 每人新台幣 400 元（分區賽報名費，以郵政匯票繳交） |
| 主辦 | 勞動部勞動力發展署技能檢定中心 |
| 類別 | [技藝與技能](/subjects/skills/)、[工程與製造](/subjects/engineering/)、[餐旅](/subjects/hospitality/) |

## 要交什麼

- 報名：網路登錄後列印的報名表、身分與學籍或勞保證明影本、每人 400 元郵政匯票（郵寄或親送）
- 分區技能競賽：依職類試題以規定材料、機具進行加工、裝配、檢修、製作成品或提供服務；報名人數過多的職類可能先辦筆試或技能測驗（現場）
- 全國技能競賽（分區賽晉級者）：實地技能操作，第一階段國手選拔賽併同舉辦（現場）

## 獎項

分區賽每職類取前 5 名優勝（參賽不足 10 人或組時取半數），另可取佳作。青年組第 1 名獎金 12,000 元、第 2 名 6,000 元、第 3 名 4,000 元，青少年組依序為 3,000 元、1,500 元、1,000 元，前 3 名另頒金、銀、銅牌，皆附獎狀；第 4、5 名及佳作頒獎狀。各職類前 5 名晉級全國技能競賽；分區賽前 3 名 3 年內參加相關職類丙級或單一級技能檢定可申請免術科測試。
