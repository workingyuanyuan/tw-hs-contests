## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-09-19（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 隊伍 | 1 至 2 人；須有指導老師 |
| 費用 | 獲選參加 APCYS 2026 者註冊費每人 375 美元（涵蓋會議期間住宿、餐飲、科學活動），往返交通自行負擔 |
| 主辦 | 中原大學半導體學院、臺灣大學海洋研究中心、臺北市麗山高中 |
| 類別 | [自然科學](/subjects/science/)、[數學](/subjects/math/)、[資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 初選：報名表、學生證與身分證影本、個人照片及專題研究作品報告書（摘要、研究動機、目的、設備器材、過程或方法、結果、討論、結論、參考資料）電子檔，word 或 pdf（線上繳交）
- 決選（初選通過者）：作品口頭報告與答問

## 獎項

決選擇選優勝者（最多 8 名學生）代表臺灣參加 APCYS2026 會議；會議依海報及口頭報告評分頒發金牌、銀牌、銅牌、佳作及特別獎。
