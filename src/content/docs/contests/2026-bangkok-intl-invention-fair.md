## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-12-09 |
| 參賽對象 | 高中職、社會人士 |
| 地區 | 全國 |
| 費用 | 每件 38,000（含 5 位發明人報名費、展位費、桌椅、電力、評比費） |
| 主辦 | 泰國國家研究院 |
| 類別 | [工程與製造](/subjects/engineering/) |

## 要交什麼

- 報名：Word 檔報名表：作品中英文名稱與摘要、作品屬性與類別、專利申請狀況、3～5 張作品相片（線上繳交）
- 參展：海報（90cm×150cm）
- 參展：作品（商品化、原型、模型或圖稿）於曼谷國際貿易展覽中心（BITEC）展位展出（現場）

## 獎項

展後由台灣發明商品促進協會安排教育部、縣市政府接見及頒發獎狀。
