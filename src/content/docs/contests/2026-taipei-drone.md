## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-04 12:00（已截止） |
| 參賽對象 | 國小、國中、高中職；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 至 5 人；須有指導老師 |
| 主辦 | 臺北市政府教育局 |
| 類別 | [工程與製造](/subjects/engineering/)、[技藝與技能](/subjects/skills/) |

## 要交什麼

- 報名：線上填寫隊伍與師生資料，附教師識別證或學校聘書等證明（線上繳交）
- 競賽：現場操作無人機完成遙控障礙賽、無人機應用賽或無人機足球賽（現場）

## 獎項

三個競賽項目的國小、國中、普高技高組各取前 3 名，每隊分別頒發 5,000 元、3,000 元、2,000 元獎金或等值禮券或獎品，每名師生獎狀一紙；另設裁判特別獎 1,000 元。
