## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-10-22（已截止） |
| 參賽對象 | 高中職；只限高中職學生 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 10 至 30 人；須有指導老師 |
| 費用 | 須繳報名費 |
| 主辦 | 臺北市政府教育局 |
| 類別 | [工程與製造](/subjects/engineering/)、[資訊與 AI](/subjects/ai-and-computing/) |

## 要交什麼

- 報名：在 FIRST 官網註冊隊伍，於 DashBoard 選擇 Taipei City Regional 報名並繳費（線上繳交）
- 區域賽：機器人檢錄、練習賽、資格賽（每隊 8 至 10 場）、聯盟選拔及淘汰賽，另有評審面談（現場）

## 獎項

評審獎項依 FIRST 官方分類，包含機器特質獎、團隊特質獎及提報獎項；場上表現獎項包括 Winner、Finalist 等；實際頒發項目依 2027 官方獎項頁面與手冊。
