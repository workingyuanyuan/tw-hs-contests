## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2027-02-18 |
| 參賽對象 | 國小、國中、高中職；高中職自成一組 |
| 地區 | 全國 |
| 隊伍 | 1 人；不設指導老師 |
| 費用 | 580 元 |
| 主辦 | 臺灣探究與實作教育學會 |
| 類別 | [外語](/subjects/foreign-languages/) |

## 要交什麼

- 考前測試：依報名後收到的測試連結完成設備及系統測試流程（線上繳交）
- 競賽：閉卷英文單字選擇題：國小組 50 題（低年級附注音），國中組與高中組 70 題，滿分 100 分，全程開攝影機（線上繳交）

## 獎項

依總人數比例頒發：金牌獎前 5%、銀牌獎前 5.01~10%、銅牌獎前 10.01~20%、優選前 20.01~30%，各獎狀 1 張；單字挑戰獎擇優若干，獎狀 1 張；未得以上獎項者獲參賽證書。獎狀為紙本，由主辦單位寄發，寄送地區限台澎金馬。
