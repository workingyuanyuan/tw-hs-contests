## 重點

| 項目 | 內容 |
| --- | --- |
| 參賽對象 | 國小、國中、高中職、五專；高中職自成一組 |
| 地區 | 全國 |
| 報名方式 | 須由學校推薦或薦送 |
| 隊伍 | 須有指導老師 |
| 主辦 | 國立臺灣藝術教育館、各直轄市及縣市政府教育局（處） |
| 類別 | [表演藝術](/subjects/performing-arts/) |

## 要交什麼

- 初賽：依縣市初賽辦法現場演出（現場）
- 決賽報名：網路填報資料，列印書面報名表加蓋學校印信，經縣市教育局（處）寄達（郵寄或親送）
- 決賽報到：參賽者名冊、劇本（含大綱）紙本10份及電子檔、劇本授權書、參賽劇本切結書（現場）
- 決賽：現場演出，以15分鐘為基準，不得超過20分鐘（現場）

## 獎項

決賽只給等第不給名次：90 分以上特優（獎狀及獎盃或獎牌），85 分以上優等、80 分以上甲等（獎狀），未滿 80 分不予獎勵；初賽獎勵由各主辦單位辦理。
