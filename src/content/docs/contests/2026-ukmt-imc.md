| 參賽對象 | 國小、國中、高中職；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 費用 | 學校自辦考場每位考生 900 元 |
| 主辦 | 英國UKMT(United Kingdom Mathematics Trust) |
| 類別 | [數學](/subjects/math/) |

## 要交什麼

- 考試（學校自辦考場、台北/新竹/台中/高雄實體考區）：60 分鐘、25 題選擇題答題卷（英文試卷附中文翻譯，禁用計算機）（現場）
- 考試（線上考區，非考區縣市、東部及離島）：以 ZOOM 進行的 60 分鐘、25 題選擇題考試（線上繳交）

## 獎項

金獎授予全球排名約前 8% 考生，銀獎約前 25%，銅獎約前 50%，未獲獎者獲參與證書，由 UKMT 英國組委會授予英文證書；另設學校最佳獎與年級最佳獎。
