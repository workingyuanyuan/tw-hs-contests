## 重點

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 2026-11-20（已截止） |
| 參賽對象 | 高中、社會人士；高中職與其他對象同組評比 |
| 地區 | 全國 |
| 費用 | 每件作品新台幣 55,000 元（含報名費及一件作品攤位費）；代展每件 10,000 元、海報每件 1,000 元；旅團約 10 萬元另計 |
| 主辦 | 科威特科學俱樂部（Kuwait Science Club, KSC）、中華台北著作權人協會、台灣發明協會 |
| 類別 | [工程與製造](/subjects/engineering/) |

## 要交什麼

- 報名：電子檔參展資料：報名表、切結書、專利證書影本或專利申請中字號、身分證與護照影本、個人照片、作品照片（線上繳交）
- 展出（親自參展）：在科威特展場攤位展出參展品（現場）
- 展出（代展）：3 分鐘內作品影片，上傳 YouTube 後提供網址（線上繳交）

## 獎項

本屆頒發超過六萬美元獎金，由科威特國王皇室組織授予獎牌與獎金；得獎者獲獎狀。
