## 收錄範圍

符合以下三項的比賽都收錄：

- 有評選
- 有名次或獎項
- 高中或高職學生可以參加

只限特定縣市的比賽、須由學校推薦的比賽也收錄。營隊、檢定考試與講座不收錄。

收錄的比賽來自各校與各平臺的公告，並追到主辦單位的簡章與官網。每一頁最後的「出處」列出讀過的文件。

## 頁面上有什麼

| 項目 | 內容 |
| --- | --- |
| 報名截止 | 新參賽者報名的最後一天；分梯次或分階段的比賽列下一個還沒過的截止日 |
| 參賽對象 | 可以參加的學制、地區，以及是否須學校推薦 |
| 費用 | 只在要收報名費或保證金時列出 |
| 要交什麼、獎項、時程 | 依主辦單位的簡章整理 |

報名截止後，比賽移到「封存」，頁面網址不變。

主辦單位的文件互相矛盾時（例如兩份簡章的截止日不同），頁面採用其中一份，並在注意事項寫明。

## 怎麼查證

截止日與參賽資格都要能在主辦單位的文件裡找到原句，程式逐句比對後才產生頁面。許多比賽另由第二個 AI 模型獨立讀取，兩次讀取的截止日或參賽資格互相矛盾時，不產生頁面。

程式每天重新讀取還能報名的比賽的文件。文件沒有變動，「最後查證」就更新為當天；文件有變動，就重新讀取整則比賽。

## 日期與時間

所有日期與時間都是臺灣時間 (UTC+8)。主辦單位寫明幾點截止時，頁面一併列出。
